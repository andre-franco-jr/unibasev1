## Unienergy App

Aplicativo móvel de monitoramento de usinas solares da **Unienergy**, desenvolvido em **Flutter**.

O app permite que clientes acompanhem o desempenho de suas usinas em tempo real, visualizando geração de energia, economia, gráficos e outras informações relevantes de forma simples e intuitiva.

### Tecnologias utilizadas

- **Flutter** (Dart)
- **Material Design 3**
- **Dio** para chamadas HTTP
- **shared_preferences** para armazenamento local
- **fl_chart** para gráficos
- **intl / flutter_localizations** para internacionalização (pt-BR)

### Requisitos

- **Flutter SDK** \(\>= 3.0.0 < 4.0.0\)
- **Dart SDK** compatível com a versão do Flutter instalada
- Android SDK configurado (para build Android)
- Emulador Android ou dispositivo físico para testes

### Configuração do ambiente

1. **Instale o Flutter**
   - Siga a documentação oficial: `https://docs.flutter.dev/get-started/install`
2. **Clone o repositório**
   ```bash
   git clone <URL_DO_REPOSITORIO>
   cd "UniEnergy App"
   ```
3. **Instale as dependências**
   ```bash
   flutter pub get
   ```
